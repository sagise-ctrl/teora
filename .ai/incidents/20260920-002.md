# Incident Report: Analyze Pipeline Failure (Model ID) + Profile Route 404 (Missing Wiring)

## Metadata
- **ID:** 20260920-002
- **Detected:** 2026-09-20 (owner reported 4x 404s + Anthropic API 400 on Haiku 4.5 model)
- **Severity:** P1 High (Begin Analyze broken + profile page broken — two user-facing flows)
- **Status:** RESOLVED (commit `83d5e18`, deploy `dpl_HW6bHEK8tq9U7oNJ4hwAyAZxs8Ay`)

## Summary

Two distinct bugs surfaced in same owner session:

1. **AI model rejection:** `OLAGON_TIERS["haiku-4.5"]` used Anthropic-dated model ID (`claude-haiku-4-5-20250514`) which Olagon gateway rejects.
2. **Profile route 404:** `profileRouter` imported in `routes/index.ts:28` but never registered with `router.use()` — long-standing latent bug since profile.ts was added.

Both surfaced as user-visible failures after INC-009 (analyze timeout) was fixed. With timeout resolved, pipeline ran far enough to surface the model error. The 404 on `/api/users/me/profile` was triggered by "mulai kerjakan" click in Task Mentor.

## Affected Features

- **Endpoint 1:** `POST /api/projects/:projectId/analyze` — pipeline: 2 sequential AI calls (Haiku 4.5 + Claude Sonnet/Opus) + transaction. Failed at first AI call.
- **Endpoint 2 (route family):** `GET /api/users/me/profile`, `PATCH /api/users/me/profile`, `POST /api/users/me/avatar`, `DELETE /api/users/me/account` — all 404'd.

## User Impact

- **Direct user impact:** Owner only (sole user at time of report)
- **Frequency:** 100% — every Begin Analyze attempt + every /akun page load
- **Wasted time:** ~10 min owner verification before root-causing

## Root Cause (CONFIRMED)

### Bug 1: Olagon Model ID Format

**Layer:** Backend AI integration (`ai.ts:38-50`)

`OLAGON_TIERS["haiku-4.5"].model` was hardcoded to Anthropic-dated ID `claude-haiku-4-5-20250514`. Olagon gateway (`https://gateway.olagon.site/anthropic`) does NOT accept Anthropic-dated IDs — only bare aliases.

**Verification:**
```bash
curl https://gateway.olagon.site/v1/models
# Returns bare aliases: claude-haiku-4-5, claude-opus-4-8, claude-opus-4-6
# NO Anthropic-dated IDs (-20250514, -20251001, etc.)

curl -X POST https://gateway.olagon.site/anthropic/v1/messages \
  -H "x-api-key: $OLAGON_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"claude-haiku-4-5-20250514","max_tokens":50,"messages":[{"role":"user","content":"hi"}]}'
# 400: The requested model 'claude-haiku-4-5-20250514' is not supported

curl -X POST https://gateway.olagon.site/anthropic/v1/messages ... \
  -d '{"model":"claude-haiku-4-5",...}'
# 200 OK ✅
```

### Bug 2: Missing Router Wiring

**Layer:** Backend routing (`routes/index.ts`)

`profileRouter` imported at `routes/index.ts:28` but NEVER registered with `router.use(profileRouter)` anywhere in the file. Verified via git log audit:

```bash
git log --all -p -- artifacts/api-server/src/routes/index.ts \
  | grep -c "router.use(profileRouter)"
# 0 — never wired in entire history
```

Long-standing latent bug. Did not surface earlier because:
- Profile page (`/akun`) is loaded only on explicit navigation
- Test fixtures often bypass `routes/index.ts` (direct router file invocation)
- No automated test scans the route registration chain

## Resolution

### Fix layers (commit `83d5e18`)

1. **`ai.ts`:** `OLAGON_TIERS["haiku-4.5"].model`: `claude-haiku-4-5-20250514` → `claude-haiku-4-5`. Added explanatory comment with verification date + Olagon bare-alias constraint.
2. **`routes/index.ts`:** Added `router.use(profileRouter)` between `subscriptionsRouter` and `usageRouter` with explanatory comment about long-standing missing wiring.
3. **Bundle rebuild:** `node build.mjs` → 21.4s, 6.6MB
4. **Deploy:** `vercel deploy --prod --yes --token $VERCEL_TOKEN` → `dpl_HW6bHEK8tq9U7oNJ4hwAyAZxs8Ay` → auto-aliased to `teora-backend.vercel.app`
