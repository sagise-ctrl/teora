## Hard Rules

1. **NEVER commit secrets, API keys, tokens, or credentials**

3. **All API routes MUST check auth + authorization** — never trust client

6. **No em dash (`—`) in frontend** — owner preference, use `:` or ASCII hyphen
7. **Conventional commits**: `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`
8. **OpenAPI is source of truth** — run `codegen` after spec changes
9. **Route order matters** — `/projects/stats` BEFORE `/projects/:projectId`
