# Prompt Pengembangan Aplikasi untuk Replit AI

## Tujuan Proyek

Bangun sebuah aplikasi web bernama **AI Academic Workspace**.

Aplikasi ini **bukan chatbot umum**, melainkan workspace khusus untuk membantu mengerjakan tugas kuliah dan karya ilmiah.

Konsep utamanya adalah:

> **Satu Tugas = Satu Workspace = Satu AI dengan konteks yang selalu diingat.**

Aplikasi digunakan oleh **satu orang saja (single user)** sehingga **tidak memerlukan sistem autentikasi**.

---

# Teknologi

Gunakan teknologi berikut:

* Laravel 12
* PHP 8.3+
* MySQL
* Tailwind CSS
* Alpine.js
* Vite

Struktur kode harus rapi, mudah dipelihara, dan mengikuti best practice Laravel.

---

# Arsitektur

Jangan membuat aplikasi seperti ChatGPT.

Yang harus dibuat adalah sistem berbasis **Project / Workspace**.

Struktur utamanya:

Dashboard
↓
Daftar Tugas
↓
Buka Tugas
↓
Workspace Tugas
↓
AI bekerja berdasarkan konteks tugas tersebut.

Semua data harus dipisahkan berdasarkan Project.

* Tahun minimal referensi

# Workspace Tugas

Saat sebuah tugas dibuka, tampilkan halaman khusus.

Layout terdiri dari beberapa tab.

## 1. Preview

Menampilkan preview dokumen terbaru.

Preview harus selalu membaca versi dokumen terbaru.

Bukan hasil AI mentah.

---

## 2. Chat AI

Setiap Project memiliki chat sendiri.

Chat Project A tidak boleh bercampur dengan Project B.

Seluruh chat harus disimpan.

Saat user mengirim prompt:

"Perbaiki BAB III"

AI harus memahami bahwa yang direvisi adalah dokumen pada project yang sedang dibuka.

Tidak perlu bertanya ulang.

---

## 3. Referensi

Buat halaman referensi yang lengkap.

Setiap referensi menampilkan:

* Judul
* Penulis
* Tahun
* Nama jurnal
* Volume
* Nomor
* DOI (jika ada)
* URL asli
* Status validasi
* Digunakan pada BAB mana

Sediakan tombol:

* Buka Link
* Cari Referensi Baru
* Perbarui Referensi
* Generate Ulang Daftar Pustaka

Referensi harus tersimpan pada database.

Bukan hanya ditampilkan di daftar pustaka.

---

## 4. Lampiran

Semua file upload ditampilkan di sini.

# Context Project

Setiap Project harus memiliki Context sendiri.

Misalnya:

* Instruksi dosen
* Metadata hasil analisis
* Referensi
* Dokumen terbaru
* Riwayat versi
* Ringkasan chat
* Lampiran

Saat user mengirim prompt baru, backend harus mengirim konteks project tersebut.

Jangan hanya mengirim prompt terakhir.

Namun jangan juga mengirim seluruh riwayat chat mentah setiap kali request.

Gunakan ringkasan konteks agar hemat token.

# Aturan AI (System Prompt)

Siapkan system prompt yang menginstruksikan AI agar:

* Selalu menggunakan Bahasa Indonesia.
* Memahami instruksi dosen secara otomatis.
* Menentukan struktur karya ilmiah secara otomatis.
* Menghasilkan tulisan akademik yang natural dan mengalir.
* Menggunakan variasi kalimat sehingga tidak terasa seperti template.
* Menghindari pengulangan frasa yang berlebihan.
* Menghasilkan paragraf yang saling terhubung secara logis.
* Mengutamakan kualitas akademik dan keterbacaan.
* Tidak membuat referensi fiktif.
* Hanya menggunakan referensi yang dapat diverifikasi.
* Mengutamakan referensi Indonesia apabila tersedia dan sesuai dengan topik.
* Menggunakan referensi yang relevan dengan permintaan tugas.
* Menjelaskan apabila referensi yang diminta tidak ditemukan daripada mengarang.
* Mengingat konteks project saat melakukan revisi.
* Saat revisi, selalu menggunakan versi dokumen terbaru.

# Tujuan Akhir

Hasil akhirnya harus berupa aplikasi **AI Academic Workspace**, bukan chatbot biasa.

Fokus utama aplikasi adalah:

* Mengelola tugas kuliah dalam bentuk Project.
* Menyimpan seluruh konteks setiap Project.
