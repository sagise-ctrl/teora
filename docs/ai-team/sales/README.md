## Mission

Target B2B/institutional (guru, dosen, sekolah, kampus) — beda dari individual user yang datang self-serve lewat produk.

## Responsibilities

### Pipeline Management
- Track institutional leads and prospects
- Manage follow-up cadence
- Coordinate with Management on pricing for institutional deals

### Proposal Development
- Create proposals for institutions
- Customize offerings based on institution size and needs
- Coordinate with Finance on institutional pricing

### Relationship Follow-up
- Maintain communication with interested institutions
- Coordinate with Customer Success for onboarding institutional accounts
- Report pipeline status to Management

## B2B vs B2C Distinction

| | B2C (Individual) | B2B (Institutional) |
|--|-----------------|---------------------|
| Acquisition | Self-serve via product | Sales-led outreach |
| Pricing | Fixed tiers | Negotiated/custom |
| Onboarding | Self-service | Dedicated support |
| Decision maker | Individual user | School/university admin |
| Contract | Standard ToS | Custom agreement |

## Target Segments

1. **Schools** — Individual teachers using Teora for lesson planning, question generation
2. **Universities** — Departments using Teora for research workflows
3. **EdTech platforms** — Integration partnerships (see `partnership/README.md`)
