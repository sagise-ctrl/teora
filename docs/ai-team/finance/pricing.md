# Pricing Strategy - Teora

## Pricing Philosophy

1. **Simple** — subscriber tahu persis berapa yang mereka bayar
2. **Transparent** — tidak ada hidden fees
3. **Fair** — harga sesuai dengan value yang diterima
4. **Sustainable** — margin positif di semua tier
5. **Competitive** — bandingkan dengan alternatif (Overleaf, Jenni AI, Scispace, etc.)

## Pricing Tiers Detail

### Tier 1: Free (Starter)
- **Price:** $0/month
- **Tokens:** 1,000/month
- **Features:** Basic AI chat, max 1 project, no export, Teora branding
- **Margin:** NEGATIVE (disubsidi ~$0.375 cost to owner)
- **Purpose:** Lead generation, user acquisition funnel
- **Limit:** 1 active project, no document export

### Tier 2: Basic (Lite)
- **Price:** $9.99/month
- **Tokens:** 10,000/month
- **Features:** All free features + 10 projects, document export, email support
- **Margin:** $0.625/1K tokens (62.5%)
- **Break-even at:** ~3,600 tokens used ($9.99 / ($1.00 - $0.375))
- **Target user:** Mahasiswa semester project

### Tier 3: Pro (Academic)
- **Price:** $29.99/month
- **Tokens:** 50,000/month
- **Features:** All basic + unlimited projects, priority AI, reference library, export PDF/DOCX, chat support
- **Margin:** $0.225/1K tokens (37.5%)
- **Break-even at:** ~48,580 tokens used
- **Target user:** Graduate student, researcher

### Tier 4: Team (Research)
- **Price:** $79.99/month
- **Tokens:** 200,000/month
- **Features:** All pro + shared projects, team management (5 seats), API access, dedicated support
- **Margin:** $0.025/1K tokens (6.25%) — **Margin tipis, perlu monitor**
- **Break-even at:** ~193,000 tokens used
- **Target user:** Research team, lab group

### Tier 5: Pay-per-use
- **Price:** $1.50 per 1,000 tokens
- **Tokens:** Purchased in bundles of 1,000
- **Features:** Same as Pro, no monthly commitment
- **Margin:** $1.125/1K tokens (75%) — **Highest margin**
- **Purpose:** Occasional users, users who want to try before subscribing

## Referral Program Economics

| Action | Cost to Owner | Value to User |
|---------|--------------|---------------|
| Referrer gets $5 credit | $5.00 | $5.00 credit |
| Referee gets 20% off first month | ~$2.00 (20% of $9.99) | 20% discount |
| Reward when referee completes first project | TBD | TBD |

**Note:** Referral cost should be < LTV (lifetime value) of acquired user.
```
LTV = Average revenue per user × Average subscription length
If LTV > $10-15 acquisition cost → referral program profitable
```

## Pricing Change Protocol

Sebelum mengubah harga:
1. **Finance review** — calculate margin impact
2. **User research** — survey willingness to pay
3. **Competitor analysis** — update comparison
4. **Soft launch** — test with small user segment
5. **Announce** — minimum 30 days notice to existing subscribers
6. **Grandfather** — existing subscribers keep old price for 6 months

## Pricing Decision Log

1. **Initial pricing** — belum final, perlu actual cost data dari AI provider
