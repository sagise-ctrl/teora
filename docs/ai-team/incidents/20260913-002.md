## Prevention (SOPs created — see `docs/ai-team/sops/`)

### SOP-001 — Deploy Verification Gate

`docs/ai-team/sops/SOP-001-deploy-verification-gate.md`

4-step gate WAJIB apply sebelum `vercel deploy --prod --yes`:
1. Local smoke test (`node -e "import('./dist/index.mjs')"`)

4. Promote ke PROD + verify alias 200 OK + auto-rollback kalau fail
