# Project Context

## Project Overview

**Name:** Teora
**Type:** AI Academic Workspace
**Description:** Aplikasi berbasis AI untuk mengelola tugas akademik dan makalah penelitian. Membantu mahasiswa dan peneliti mengelola project akademik dengan AI context, riwayat dokumen, database referensi, dan timeline aktivitas.

## Core Problem

Mahasiswa dan peneliti menghadapi tantangan dalam mengelola project akademik yang kompleks -- banyak dokumen, referensi, chat dengan AI, dan aktivitas yang tersebar. Teora menyediakan workspace terpadu yang memahami konteks project secara keseluruhan.

## Core Features

- **Project Management** -- workspace akademik dengan metadata dan status
- **AI-Powered Document Generation** -- generate dan tulis dokumen dengan bantuan AI
- **Reference Management** -- database referensi pustaka (buku, jurnal, paper)
- **AI Chat** -- conversational AI dengan konteks project-aware
- **Timeline Activity** -- log aktivitas project (created, updated, status change, dll.)
- **Document Export** -- export dokumen ke PDF, DOCX, dan format lainnya

## Target Users

- Mahasiswa (S1, S2, S3)
- Peneliti akademik
- Dosen dan akademisi

## Tech Stack

### Frontend (artifacts/academic-workspace)
- React 19
- Vite (bundler)
- Tailwind CSS v4 (CSS-first configuration)
- TanStack Query (server state)
- wouter (routing)
- Supabase Client SDK (auth)

### Backend (artifacts/api-server)
- Express 5
- Drizzle ORM
- PostgreSQL (Supabase)

### Libraries (lib/)
- `api-spec` -- OpenAPI YAML, single source of truth
- `api-zod` -- Zod schemas (generated from OpenAPI)
- `api-client-react` -- TanStack Query hooks (generated by Orval)
- `db` -- Drizzle ORM schema

## Authentication

- **Provider:** Supabase Auth
- **Method:** Email/password
- **Validation:** JWT validated on backend via `jose` library + JWKS
- **Flow:** Supabase Auth (frontend) issues JWT -> backend validates JWT on every request

## Deployment

| Layer | Platform | Details |
|-------|----------|---------|
| Frontend | Vercel | Preview deployments on PR, production on main |
| Backend | Vercel Function | Express 5, serverless, auto-scales, same domain as frontend |
| Database | Supabase | PostgreSQL, connection via pooler |

**Key constraint:** Backend deployed as Vercel Function alongside frontend. Frontend calls `/api/*` directly (same origin). `VITE_API_URL` defaults to `/api` in production.
